= xactor: a deterministic actor system for {cpp}
:toc: left
:toclevels: 1
:idprefix:
:sectanchors:
:example-caption!:
:attribute-missing: warn

xactor is a header-only, deterministic actor system for {cpp}20, one of the
libraries of https://github.com/webcpporg/webcpp[webcpp]. Its actors handle
one message at a time, on one thread, in an order that depends only on the
order the messages were sent; every execution is paid from a budget of fuel;
and time is a number the host brings.

This page teaches xactor concept by concept: why each exists, its smallest
example, its variations and its rules. Every program it shows was compiled
and run, natively and, but for the program built on Boost.Asio, for
wasm32-wasip2 and wasm32-wasip3, and printed the output shown under it. The
<<reference,reference>> that closes it lists every name the headers declare.
